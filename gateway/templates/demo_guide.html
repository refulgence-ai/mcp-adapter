🎮 Refulgence Demo Guide

Simple, step-by-step instructions for demonstrating the AI Agent Security Gateway

1️⃣ Opening - The Problem (2 minutes)

Start at: http://localhost:8080/admin
Say: "Imagine you have AI coding agents with access to your production databases. How do you ensure they don't accidentally drop tables or expose sensitive data? Refulgence is an AI Agent Security Gateway - think of it as a firewall specifically for AI agents."
Click ⚡ Simulate Event in the header
Say: "Every AI agent action goes through our governance engine. Let me show you how this works."

2️⃣ Core Demo - Governance in Action (5 minutes)

A. Test a Dangerous Query

Location: Main dashboard query tester (center of page)
In the query box, type: DROP TABLE customers;
Click 🧪 Test Query
Say: "The system immediately blocks destructive operations. This happens in real-time before the query reaches your database."

B. Test a PII Access Query

Change query to: SELECT * FROM customers WHERE ssn IS NOT NULL
Click 🧪 Test Query
Say: "PII access triggers our approval workflow. The query is held until authorized stakeholders approve it."

C. Show the Policy Matrix

Click the 📋 Policy Matrix tab
Click Load Demo Matrix (in the blue demo box)
Say: "This is where you configure who can do what. Notice coding agents are restricted while security analysts have override capabilities."
Click any cell in the matrix to show it's editable
Say: "Policies are completely customizable. You can set ALLOW, DENY, or REQUIRE_APPROVAL for any combination of user type and action."

3️⃣ User Management & Inspection (2 minutes)

Click the 👥 User Management tab
Click Load Demo Users (in the blue demo box)
Click Test Inspector
Say: "Every user and AI agent has a complete audit trail. We track permissions, access patterns, and can instantly suspend access if needed."

4️⃣ Activity Analysis (2 minutes)

Navigate to: http://localhost:8080/admin/drill-down
Say: "This is our forensic analysis interface. Every governance decision is logged and searchable."
Click on any event in the activity feed (center panel)
Say: "You can drill down into any event to see exactly what was attempted, who attempted it, and what governance decision was made."
Use the severity filters (left panel) - uncheck "Info" and "Success"
Say: "Filter by severity, time range, or search for specific patterns. Perfect for compliance reporting and security audits."

5️⃣ Closing - The Value (1 minute)

Return to: http://localhost:8080/admin
Click 🎮 Start Demo Tour to show the self-guided feature
Key Points to Emphasize:
  • Real-time protection against AI agent mistakes
  • Complete audit trail for compliance
  • Customizable policies for your organization
  • Multi-stakeholder approval workflows
  • Zero-trust approach to AI agent activities

🆘 Quick Fixes

If nothing is loading:
Run in terminal: docker-compose restart gateway
If you need sample data:
Click 🧪 Generate Demo Data in the admin header
If demo buttons aren't working:
Refresh the page (Cmd+R or Ctrl+R)
